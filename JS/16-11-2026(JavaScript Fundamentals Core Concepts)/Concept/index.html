1. Introduction to JavaScript

JavaScript is a high-level programming language used to create dynamic and interactive web applications.

Why do we use JavaScript?

  • To make web pages interactive.
  • To handle user events.
  • To validate forms.
  • To update HTML content dynamically.
  • To communicate with APIs.
  • To develop frontend and backend applications.

Role of HTML, CSS and JavaScript

HTML: Structure of a webpage.

CSS: Styling and layout of a webpage.

JavaScript: Behaviour and interactivity.

2. Variables: var, let and const

Variables are containers used to store data values.

Keyword Scope Reassignment Redeclaration
var Function Allowed Allowed
let Block Allowed Not allowed in same scope
const Block Not allowed Not allowed in same scope

Syntax


var StudentName = "Rahul";

let StudentAge = 22;

const CollegeName = "ABC College";

Use let when a variable needs reassignment and const when the variable binding should not be reassigned.

3. JavaScript Data Types

Data types define the type of value stored in a variable.

Primitive Data Types

  • String
  • Number
  • Boolean
  • Undefined
  • Null
  • BigInt
  • Symbol

Non-Primitive Data Types

  • Object
  • Array
  • Function

Example


let StudentName = "Rahul";
let StudentAge = 22;
let IsSelected = true;
let StudentAddress;
let StudentMarks = null;

console.log(typeof StudentName);
console.log(typeof StudentAge);
console.log(typeof IsSelected);
console.log(typeof StudentAddress);
console.log(typeof StudentMarks);

Note: JavaScript returns "object" for typeof null. This is a historical language quirk.

4. Type Conversion

Type conversion means changing a value from one data type to another.

String Conversion


let Age = 25;

let Result = String(Age);

console.log(Result);
console.log(typeof Result);

Number Conversion


let Value = "100";

let Result = Number(Value);

console.log(Result);
console.log(typeof Result);

Boolean Conversion


let Value = 1;

let Result = Boolean(Value);

console.log(Result);

5. Operators and Expressions

Operators are symbols used to perform operations on values.

Operator Type Examples
Arithmetic +, -, *, /, %, **
Assignment =, +=, -=, *=
Comparison ==, ===, !=, !==, >, <
Logical &&, ||, !
Ternary condition ? value1 : value2

Example


let FirstNumber = 20;
let SecondNumber = 10;

console.log(FirstNumber + SecondNumber);
console.log(FirstNumber > SecondNumber);
console.log(FirstNumber === SecondNumber);

6. Conditional Statements

Conditional statements execute different blocks of code depending on whether a condition is true or false.

Types

  • if statement
  • if-else statement
  • else-if ladder
  • switch statement
  • ternary operator

Example


let Marks = 85;

if (Marks >= 90) {
    console.log("Grade A+");
}
else if (Marks >= 80) {
    console.log("Grade A");
}
else {
    console.log("Grade B or below");
}

7. Loops

Loops are used to execute a block of code repeatedly until a condition is satisfied.

Types of Loops

  • for loop
  • while loop
  • do-while loop
  • for...of loop
  • for...in loop

Example


for (let Number = 1; Number <= 5; Number++) {
    console.log(Number);
}

Break and Continue

  • break: Stops the loop.
  • continue: Skips the current iteration.

8. Functions

A function is a reusable block of code designed to perform a specific task.

Function Declaration


function AddNumbers(FirstNumber, SecondNumber) {
    return FirstNumber + SecondNumber;
}

console.log(AddNumbers(10, 20));

Function Expression


const MultiplyNumbers = function(FirstNumber, SecondNumber) {
    return FirstNumber * SecondNumber;
};

console.log(MultiplyNumbers(5, 4));

Arrow Function


const SquareNumber = (Number) => {
    return Number * Number;
};

console.log(SquareNumber(5));

Callback Function


function DisplayResult(Result) {
    console.log(Result);
}

function CalculateSum(A, B, Callback) {
    let Total = A + B;
    Callback(Total);
}

CalculateSum(10, 20, DisplayResult);

9. Arrays

An array stores multiple values in a single variable. Array indexing starts from zero.

Example


const Students = ["Rahul", "Priya", "Kiran"];

console.log(Students[0]);

Students.push("Anil");

console.log(Students);

Important Array Methods

  • push() and pop()
  • shift() and unshift()
  • map()
  • filter()
  • reduce()
  • find() and findIndex()
  • some() and every()
  • sort() and includes()

10. Objects

An object stores data in key-value pairs. It can also contain functions called methods.

Example


const Student = {
    StudentName: "Rahul",
    StudentAge: 22,
    Course: "JavaScript",

    DisplayDetails: function() {
        console.log(this.StudentName);
        console.log(this.Course);
    }
};

console.log(Student.StudentName);

Student.DisplayDetails();

11. String Methods

String methods are used to work with and manipulate text.

  • toUpperCase()
  • toLowerCase()
  • trim()
  • includes()
  • startsWith()
  • endsWith()
  • slice()
  • substring()
  • replace()
  • split()

let Message = "  Hello JavaScript  ";

console.log(Message.length);
console.log(Message.trim());
console.log(Message.toUpperCase());
console.log(Message.includes("JavaScript"));

12. Number Methods

Number methods help convert, validate, and format numeric values.

  • Number()
  • parseInt()
  • parseFloat()
  • toFixed()
  • Number.isNaN()
  • Number.isInteger()
  • Math.round()
  • Math.floor()
  • Math.ceil()
  • Math.random()

let Price = 99.567;

console.log(Price.toFixed(2));
console.log(Math.round(Price));
console.log(Math.floor(Price));
console.log(Math.ceil(Price));
